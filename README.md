# AgroControl CBA

"AgroControl CBA" es un sistema desarrollado en Python para la gestión y control de productos, lotes, ventas y movimientos dentro de un entorno agrícola.

El sistema permite registrar, consultar y validar información mediante archivos JSON, aplicando conocimientos de programación, manejo de archivos, validación de datos y control de versiones con Git.

## Instrucciones de ejecución

**1. Requisitos:**

Python 3.x

Visual Studio Code

Git

**2. Ejecución del programa:**

Clonar o descargar el repositorio.

Abrir la carpeta principal del proyecto.

Abrir una terminal en la carpeta.

**3. Ejecutar el archivo principal:**

python main.py

Utilizar el menú principal para acceder a las diferentes funcionalidades.

## Reglas principales

1. Validar los datos antes de registrarlos.

2. Evitar el ingreso de información vacía o incorrecta.

3. Mantener organizada la información en los archivos JSON.

4. Utilizar nombres claros y descriptivos para variables, funciones y archivos.

5. Mantener una estructura organizada del código.

6. Registrar los cambios importantes mediante commits de Git.

7. Mantener actualizado el repositorio.

8. Conservar la integridad de la información almacenada.

## Funcionalidades principales

1. Gestión y registro de productos.

2. Validación de productos.

3. Gestión de lotes.

4. Registro de ventas.

5. Registro de movimientos.

6. Lectura y almacenamiento de información mediante archivos JSON.

7. Menú principal para acceder a las funcionalidades del sistema.
